# Product

## Register

product

## Users
Newcomers to Edge.js — developers learning AdonisJS templating, often early in their web framework journey. They are curious but not yet confident with Edge syntax, conditionals, loops, or the concept of template engines. They benefit from immediate visual feedback and clear, encouraging guidance.

## Product Purpose
A browser-based playground for writing Edge.js templates and previewing the rendered output with live JSON state. It accelerates learning by making the compile-evaluate loop instant and visual — no server setup required.

## Brand Personality
Friendly, approachable, encouraging. Three words: **clear, warm, playful**. The interface should feel like a helpful mentor, not a cold IDE. Every interaction should reinforce "you can do this."

## Anti-references
- Cluttered IDE layouts (VS Code-alikes with too many panels)
- Generic dark-mode "developer tool" aesthetic
- Overwhelming syntax documentation alongside the editor
- Complex dashboards with sidebars, breadcrumbs, or deep navigation
- SaaS hero-metric templates or feature grids

## Design Principles
1. **Show, don't tell** — The rendered output is the star. The template and state are supporting actors.
2. **Immediate feedback** — Every keystroke should feel connected to the result. No hidden steps.
3. **Friendly confidence** — Error states should guide, not punish. Success should feel rewarding.
4. **No walls of text** — Documentation is discoverable, not front-loaded. The interface teaches through interaction.
5. **Playful precision** — Fun, warm details (micro-interactions, delightful icons) without sacrificing clarity or usefulness.

## Accessibility & Inclusion
- WCAG 2.1 AA minimum
- Keyboard-navigable tabs and controls
- Reduced motion respected for all animations
- Sufficient color contrast for code syntax and error states
